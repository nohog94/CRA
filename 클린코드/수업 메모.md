DI (Dependency Injection) 
객체가 스스로 의존 객체를 생성하지 않고 **외부에서 주입받는 방식**을 말해요.
CallMan cm = new Callman()
cm.work(new Smartphone);
cm.work(new Brickphone);

Factory 
객체 생성 로직을 별도의 **팩토리 클래스/메서드로 분리**해서 캡슐화하는 패턴입니다.
class Engine {
    // ...
}

class EngineFactory {
    public static Engine createEngine() {
        return new Engine();  // 생성 로직을 여기서 담당
    }
}

Engine engine = EngineFactory.createEngine();  // 직접 생성하지 않고 Factory 사용
